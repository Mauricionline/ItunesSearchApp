# iTunes Search App

A modern React application to search for content on iTunes using the official iTunes Search API.

## Features

- **Real-time search** in the iTunes database
- **Filter by media type** (music, videos, movies, podcasts, etc.)
- **Paginated results** with load more functionality
- **Sorting** results A-Z and Z-A
- **State management** for loading, error, and empty states
- Built with **TypeScript** for strong type safety

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- iTunes Search API

## Installation

1. Clone the repository.

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open your browser at:

```
http://localhost:5173
```

## Usage

**To search for content:**

- Enter a search term.
- Select the media type.
- Sort results in ascending or descending order.
- The search will return the first 10 results. You can load more by clicking the "Show more results" button.
